# WindowResizeHUD

Macのユーティリティ。**他のアプリのウインドウをマウスでリサイズしている間**、ウインドウ全体を矩形で囲み、カーソルの近くに現在のサイズ (幅 × 高さ、pt) を表示します。

## 動作イメージ

| 状況 | 表示 |
| --- | --- |
| ウインドウの縁でドラッグし、実際にサイズが変わり始めたら | その瞬間から矩形とサイズを表示 |
| リサイズ中 | 矩形と数値がウインドウに追従して更新 |
| マウスボタンを離す | 非表示 |

縁にカーソルを合わせただけ (ホバー) では表示しません。また、タイトルバーのクリックやウインドウの移動 (サイズが変わらない操作) でも表示しません。

## ビルドと実行

```bash
bash build_app.sh
open WindowResizeHUD.app
```

- `WindowResizeHUD.app` が生成されます (SwiftPMでビルドし、アプリバンドルにまとめます)。
- 起動すればそのまま使えます。アクセシビリティ許可などの設定は不要です (マウス操作の監視とウインドウ矩形の取得には許可が要らないため)。

## 署名について (任意)

署名は必須ではありません。証明書があれば安定した署名になり、なければその場限りの署名 (ad-hoc) になりますが、動作は同じです。証明書で署名したい場合は、自己署名の証明書を作ってビルド時に指定します。

1. キーチェーンアクセス → 証明書アシスタント → 証明書を作成
   (名前は任意。例: `Local Signing`。種類は「コード署名」)
2. ビルド時に証明書名を指定する

```bash
SIGN_IDENTITY="証明書の名前" bash build_app.sh
```

証明書名を指定しない場合、見つかった最初の証明書で自動的に署名します。証明書が複数ある場合は、意図しないものが選ばれることがあるので、`SIGN_IDENTITY` での明示指定を推奨します。証明書がない場合はアドホック署名になります。

証明書の名前は次のコマンドで確認できます。

```bash
security find-identity -v -p codesigning
```

## 仕組み

- `CGWindowList` で画面上のウインドウ一覧 (位置と大きさ) を取得
- グローバルマウスモニタで押下/ドラッグ/解放を監視し、ドラッグ開始位置からリサイズ対象のウインドウを特定 (探索はカーソルを含む一番手前のウインドウで打ち切る)
- 押下時点のサイズを覚え、実際にサイズが変わった時点で初めて表示する
- ドラッグ中は対象ウインドウだけを `CGWindowList` (`.optionIncludingWindow`) で約60fps取得して追従
- オーバーレイは「対象ウインドウ＋ラベル用の余白」の大きさの小さなウインドウで、対象に追従して動く。マウスイベントは透過する

## 制限・注意

- 他アプリのウインドウの「リサイズ開始/終了」を知らせる公式APIがないため、マウス操作とウインドウ矩形の変化から推定しています。
- 表示するサイズは pt (ポイント、論理サイズ) です。Retina (2倍表示) では、pt の値は物理ピクセル数の約半分になります。解像度設定を「スペースを拡大」などに変えている場合は、ちょうど2倍にはなりません。
- 一部のアプリはマウスボタンを離すまでウインドウサイズが変わりません。その場合は表示されません。
- macOS 13 以降が必要です。
