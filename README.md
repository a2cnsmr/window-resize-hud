# Window Resize HUD

他のアプリのウインドウをマウスでリサイズするときに、

- ウインドウ全体を四角い矩形で囲み
- カーソルの近くにサイズ (幅 × 高さ、ピクセル) を表示し
- リサイズ中は矩形と数値がリアルタイムに追従し
- リサイズが終わると自動で消える

Mac 用のメニューバー常駐ユーティリティです。

## 動作イメージ (理想系との対応)

| 理想系 | 実装 |
|---|---|
| ウインドウの淵にカーソルを当てるとリサイズカーソルになる | これは macOS 本体が各アプリのウインドウで出します。このアプリのオーバーレイはマウスイベントを透過するので邪魔しません |
| その時にウインドウ全体を矩形で囲む | カーソルがウインドウの縁 (約6ptの帯) に入った瞬間に、アクセントカラーの矩形を表示 |
| カーソル近くにサイズを表示 | カーソルの右上に `幅 × 高さ` を表示 (画面端では自動で内側に収めます) |
| リサイズ中は矩形も値も変わる | ドラッグ中は約60fpsでウインドウの矩形を取得し直して追従 |
| 終われば非表示 | マウスボタンを離した時点で非表示 |

## ビルドと実行 (Mac が必要です)

前提: macOS 13 以降、Xcode または Command Line Tools (swift が使えること)。

```bash
# .app を組み立てる
bash build_app.sh

# 起動する
open WindowResizeHUD.app
```

アプリ単体で試すだけなら `swift run` でも起動できます。

## 初回だけ: アクセシビリティ許可

他のアプリのウインドウ操作やグローバルなマウス監視には許可が必要です。

1. アプリを起動する (許可ダイアログが出ます)
2. システム設定 > プライバシーとセキュリティ > アクセシビリティ で
   「WindowResizeHUD」をオンにする
3. アプリを一度終了して再起動する

メニューバーのアイコン (破線の四角) からも設定画面を開けます。

## 仕組み

- `CGWindowListCopyWindowInfo` で画面上のウインドウの位置と大きさを取得
- `NSEvent.addGlobalMonitorForEvents` でマウスの移動/押下/ドラッグ/解放を監視
- カーソル下の一番手前のウインドウについて、縁の帯にカーソルがあるかを判定
- 表示はマウスを透過する全画面オーバーレイウインドウ (`ignoresMouseEvents = true`) に描画

## 制限・注意

- 他アプリの「リサイズ開始/終了」を知らせる公式 API はないため、マウス操作と
  ウインドウ矩形の変化から推定しています。キーボードでのリサイズや、
  アプリ独自のリサイズ方法では表示されないことがあります。
- フルスクリーン表示中のウインドウなど、特殊な状態では効かない場合があります。
- 署名・公証はしていません。自分の Mac でビルドして使う前提の試作です。
  他人に配る場合は Developer ID 署名と公証が必要です。
- サイズはポイントではなく、ウインドウの論理サイズ (ピクセル相当の pt 値) です。
  Retina の物理ピクセル数とは異なります。

## ファイル構成

- `Package.swift` — Swift Package 定義
- `Sources/WindowResizeHUD/main.swift` — 本体 (単一ファイル)
- `build_app.sh` — .app バンドルを組み立てるスクリプト (アイコンの .icns 化も行う)
- `AppIcon.iconset/` — アイコンの各サイズ PNG (16〜512px、@2x 含む)
- `AppIcon-1024.png` — アイコンのマスター画像
- `make_icon.py` — アイコンを再描画するスクリプト (色や形を変えたいとき)
